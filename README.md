# 프레젠스월드 재고현황 자동화

매주 이카운트 재고 데이터를 `프레젠스월드_재고현황.xlsx`에 자동으로 업데이트하는 스크립트입니다.

## 필요 파일

| 파일 | 출처 | 설명 |
|------|------|------|
| 창고별재고현황.csv | 이카운트 → 재고1 → 출력물 → 창고별재고현황 | 기준일: 지난주 금요일, 창고: 각부서 하늘색 창고만 선택 |
| ESA009M_품목마스터.csv | 이카운트 → 기초정보 → 품목 → ESA009M | 입고단가 기준표 |
| 프레젠스월드_재고현황.xlsx | 기존 작업 파일 | 브랜드별 시트 + 통계 시트 |

## 설치

```bash
pip install openpyxl
```

## 사용법

```bash
python inventory_update.py \
    --inventory 창고별재고현황.csv \
    --master ESA009M_8.csv \
    --template 프레젠스월드_재고현황.xlsx \
    --date 2026-06-23
```

> `--date` 는 작업 당일 날짜(월요일)를 입력하세요.  
> 자료 기준일(지난주 금요일)과 달라도 됩니다.

출력 파일은 기본적으로 원본을 덮어씁니다. 별도 경로 지정 시 `--output` 옵션 사용:

```bash
python inventory_update.py ... --output 프레젠스월드_재고현황_260623.xlsx
```

## 설정 변경

`inventory_update.py` 상단의 두 딕셔너리를 수정하세요.

### 창고명 매핑 (`WAREHOUSE_TO_DEPT`)

이카운트 창고명이 다를 경우 여기서 추가/수정:

```python
WAREHOUSE_TO_DEPT = {
    "온라인창고": "온라인",   # → '온라인 수량' 컬럼
    "영업창고":   "영업",     # → '영업 수량' 컬럼
    "위탁매장":   "영업_위탁매장",
    "사업지원창고": "사업지원",
    "컨기":       "컨기",
}
```

### 브랜드명 매핑 (`BRAND_TO_SHEET`)

이카운트에서 새 브랜드가 추가되면 여기서 시트명에 연결:

```python
BRAND_TO_SHEET = {
    "굿스마일": "굿스마일",
    "부시로드": "부시로드",
    # ... 추가
}
```

## 처리 흐름

```
창고별재고현황.csv ──┐
                     ├──► inventory_update.py ──► 프레젠스월드_재고현황.xlsx (업데이트)
ESA009M 품목마스터 ──┘                         └──► 전주 대비 변동 리포트 (터미널 출력)
```

1. 품목마스터에서 입고단가 로드
2. 창고별재고현황 파싱 → 브랜드별 시트에 수량/단가 업데이트
3. 통계 시트에 새 날짜 컬럼 추가 + 수식 연결
4. 전주 대비 ±5% 이상 변동 품목 리포트 출력

## 주의사항

- 직영사업부(`메가하우스_직영` 시트)는 별도 메일 수신 자료를 수동으로 붙여넣기해야 합니다.
- 미쿠감사제 등 특수 시트는 이카운트 창고명에 `컨기` 창고가 있어야 자동 반영됩니다.
- 노션 업로드 및 강차장님 보고는 수동으로 진행하세요.
